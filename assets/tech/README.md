# Technology icons

Devicon SVGs are from https://github.com/devicons/devicon (MIT; see LICENSE-devicon.txt). Filenames correspond to the upstream icon names; Rails uses its plain variant, others use original variants.

Aseprite comes from https://github.com/simple-icons/simple-icons/blob/develop/icons/aseprite.svg (CC0; see LICENSE-simple-icons.txt).

Local Storage, Pixel Art, and RPG Maker use custom generic storage, pixel face, and sword symbols respectively; these are illustrative symbols, not official logos. Ruby represents the Ruby / RGSS entry. All product logos belong to their respective owners.
